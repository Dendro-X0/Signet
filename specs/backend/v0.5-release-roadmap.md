# Design: v0.5.0 release roadmap

**Band:** v0.5.0 public preview cut → 0.5.x → v1.0.0  
**Status:** ready  
**Depends on:** Phases 13–15 done; engine on `main` (inspect, hybrid, CLI detect, TUI polish)  
**Owners:** [`docs/roadmap.md`](../../docs/roadmap.md), this file, [`demo-and-dogfood-design.md`](demo-and-dogfood-design.md) §Cut  
**Plan alignment:** Tag a demoable public preview without inventing a parallel north star; defer GUI / brew / .NET to Beyond.

---

## Version policy (frozen)

| Tag | When |
|-----|------|
| **v0.5.0** | Public **preview**: Phases 13–15 + engine features on `main`; dogfood notes may be **partial** |
| **0.5.x** | Friction fixes from dogfood; complete real-app Sign→Prove→Check notes; demo recording published |
| **v1.0.0** | Full gate: dogfood shows successful Sign→Prove→Check on ≥1 real app; narrative stable; no “preview” framing |

Source of cut checklist truth: [demo-and-dogfood-design.md](demo-and-dogfood-design.md) §Cut. This file does not fork conflicting rules.

---

## In scope for the v0.5.0 cut

1. Inventory credit for work already on `main` since v0.4.0 (see roadmap § Already on main).
2. Phase 16 process: dogfood notes (partial OK), CHANGELOG, version bump, tag, `release-cli`, install+verify spot-check.
3. Release body announces dual-path + demo link.

## Out of scope (cut and 0.5.x)

- Desktop GUI, Homebrew / winget, .NET adapters.
- Host-signing / notarizing the Signet CLI binary as a hard requirement (document checksum-only honesty if needed).
- Full Play Console / App Store Connect / EAS automation.
- Claiming SmartScreen / Gatekeeper silence.

## Cut checklist (mirror §Cut)

Before tagging **v0.5.0**:

| # | Check |
|---|--------|
| 1 | Phases 13–15 done |
| 2 | Dogfood notes merged under `docs/dogfood/` (partial OK for preview) |
| 3 | CHANGELOG Unreleased → `## 0.5.0` (include CLI detect + TUI polish) |
| 4 | Workspace version → `0.5.0` |
| 5 | START-HERE / README status version |
| 6 | `cargo test -p signet` + `clippy -D warnings` |
| 7 | Tag `v0.5.0` → `release-cli` green |
| 8 | Spot-check install + `signet verify` against release `SHA256SUMS` |
| 9 | Release body: dual-path + demo link |

**Blocked for coding until:** maintainer dogfood notes exist (or explicit partial stub). Tagging is a maintainer process step.

## Already on main (credit toward 0.5.0)

| Area | Evidence |
|------|----------|

## After tag — 0.5.x → v1.0.0

| Band | Focus | Exit |
|------|--------|------|
| **0.5.x** | Finish dogfood; fix friction from notes; publish demo recording; cargo-install honesty if unmanaged installs confuse users | Successful Sign→Prove→Check on ≥1 real app documented |
| **v1.0.0** | Phase 16 acceptance fully checked; narrative stable; drop “preview” framing | Tag per full gate above |

Then handoff next step = Beyond item or maintenance ([`docs/roadmap.md`](../../docs/roadmap.md) § Beyond v1.0).
