## Sample A — Pre-release checklist (slice)

Run before you tag or upload a Windows installer.

### Identity & secrets

- [ ] Signet identity created (`signet identity create`) — fingerprint known  
- [ ] Identity / PFX / keystore **not** in git  
- [ ] No passwords or private keys in `TRUST.md`

### Check before publish

- [ ] `signet verify` passes on the release tree (or `--artifact` for the installer)  
- [ ] `signet inspect --file path\to\setup.exe` reviewed  
- [ ] Release notes do **not** promise SmartScreen silence

## Sample B — Demo `TRUST.md` shape

Illustrative only — generated by `signet trust` in the [demo kit](../demo.md). Fingerprints and paths will differ on your machine.

```markdown
# TRUST.md

## Publisher

- **App:** HelloSignet Demo
- **Declared tier:** self_signed_host

## Integrity

- Compare this fingerprint with `signet identity show`.
- Verify downloads with `SHA256SUMS` via `signet verify`.

## Honesty

Self-signed Windows builds may show SmartScreen.
Matching checksums proves **integrity**, not Microsoft reputation.
We never ask users to install certificates into Trusted Root.
```
