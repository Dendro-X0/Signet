# Demo kit (recording & local smoke)

Fixed fixture under [`demo/`](../demo/) so GIF/video and local tests replay the same **Sign → Prove → Check** path without a real Electron/Tauri app.

## Prereqs

1. Signet on `PATH` (`signet --version`), **or** from the repo:
   - Bash: `export SIGNET="cargo run -q -p signet --"`
   - PowerShell: `$env:SIGNET = 'cargo run -q -p signet --'`
2. Optional host tools: `signet doctor` (fake `dist/*.exe` is **not** a real PE — happy path uses `--no-sign`).

## CLI happy path (scripted)

From repo root:

```bash
./demo/scripts/happy-path.sh
```

```powershell
pwsh ./demo/scripts/happy-path.ps1
```

Expected phrases / steps (for recording captions):

| Step | Look for |
|------|----------|
| Doctor | tooling checks (optional failures OK) |
| Identity | `HelloSignet Demo` / fingerprint |
| Trust | wrote `TRUST.md` · tier language |
| Build | discover under `dist/` · `SHA256SUMS` |
| Verify | fingerprint / checksum lines |
| Inspect | `platform=windows` / `linux` · `unsigned` or `unknown` |
| Graduate | honesty: no SmartScreen silence |

## TUI recording (visual)

1. Run the script once so identity + TRUST + sums exist.
2. Terminal ~100×30 or larger; dark theme optional.
3. `cd demo/fixture && signet`
4. Open **Guided setup** — walk Sign → Prove → Check (skip rebuild if artifacts exist).
5. Show **Graduate notes** once (no secrets on screen).
6. Say once on voiceover: self-sign ≠ SmartScreen / Gatekeeper silence.

## Verify a real Signet release (downloaders)

After install:

```bash
# fetch release checksums
curl -fsSL -o /tmp/signet-SHA256SUMS \
  https://github.com/Dendro-X0/Signet/releases/latest/download/SHA256SUMS
# compare to the binary you downloaded (adjust name/OS)
# shasum -a 256 signet-…   # or certutil -hashfile … SHA256 on Windows
```

Or point `signet verify --sums …` at a directory that contains both the binary and `SHA256SUMS` from the same release.

## Layout

```text
demo/
  README.md
  fixture/
    signet.toml          # framework = electron
    package.json         # electron scan marker
    dist/HelloSignet.exe # placeholder bytes
    dist/HelloSignet.AppImage
    dist/HelloSignet.apk
  scripts/
    happy-path.sh
    happy-path.ps1
```

`.signet/`, `TRUST.md`, and `SHA256SUMS*` under `fixture/` are gitignored (generated by the script).
